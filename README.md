I flirted with Kotlin and Swift, but Flutter stole my heart — so now I'm all in. UI/UX, architecture, state management, backends, and lately, teaching apps a little AI so they can actually solve people's problems (not just look pretty).

Building things. Breaking things. Learning either way. 🚀
